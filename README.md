# 🎬 Movie Talk | Cine Retrô Vintage

> Uma plataforma nostálgica para explorar filmes clássicos e favoritos por gênero, com um design que remete às noites de cinema.

## 🖼️ Preview do Projeto

Um site cinéfilo, que vis trazer novidades do mundo do cinema antigo para sua tela e no seu conforto.
Visamos trazer noticias, e informações de onde assistir/comprar os ingressos dos clássicos filmes das telonas!


## ✨ Funcionalidades

O site **Movie Talk** oferece a seguinte experiência:

* **Navegação Rápida:** Menu lateral e menu de categorias em *dropdown* para acesso direto a diferentes seções e gêneros.
* **Design Retrô-Vintage:** Esquema de cores (vermelho/dourado) e fontes que evocam a estética clássica do cinema, conforme definido nas variáveis CSS (`--retro-red`, `--accent-color`).
* **Organização por Gênero:** Filmes organizados em seções como Ação, Animação, Drama, Ficção Científica, Comédia e Terror.
* **Acordeão de Filmes:** As listas de filmes são inicialmente limitadas e podem ser expandidas (efeito de acordeão) ao clicar no título da seção, gerenciado via JavaScript.
* **Efeitos Visuais:** Efeitos de luz sutil (`box-shadow`, `radial-gradient`) aplicados nos cards de filmes e seções no evento `:hover`.
* **Busca Dinâmica:** Barra de busca que oferece resultados em *dropdown* baseados em uma lista local (`filmes.json`).

## 🛠️ Tecnologias Utilizadas
| **Estrutura** | HTML5 | Conteúdo principal e links de navegação. |
| **Estilização** | CSS3 | Estilos com variáveis (cores retro), layout responsivo (`@media (max-width: 768px)`), e animações de hover. |
| **Interatividade** | JavaScript (Puro) | Lógica do menu lateral, controle do acordeão de seções (`lista-filmes-expandida`) e funcionalidade de busca dinâmica. |
| **Ícones** | Font Awesome | Ícones de redes sociais e o menu hamburguer. |
